✅ Phase 2 : Infrastructure AWS Low-Cost via Terraform

Objectifs : Générer l’infrastructure complète AWS Cinephoria (EC2, S3, CloudFront, Route53, ACM), compatible Free Tier.


Je veux construire toute l’infrastructure AWS low-cost de Cinephoria (backend + frontend) via Terraform, en utilisant ces domaines :

www.cinephoria.eu  → CloudFront (prod)

staging.cinephoria.eu → CloudFront (staging)

api.cinephoria.eu → EC2

staging-api.cinephoria.eu → EC2 (même instance ou ports séparés)


👉 Une seule instance EC2 héberge deux environnements backend distincts :

Production → Docker + Nginx → port 5000

Staging → Docker + Nginx → port 5001
👉 Route53 dirige :

api.cinephoria.eu → port 5000 via Nginx

staging-api.cinephoria.eu → port 5001 via Nginx



Architecture low-cost :

1x EC2 t2.micro/t3.micro (backend + PostgreSQL via Docker)

S3 (2 buckets)

CloudFront (2 distributions)

Route53 (Hosted Zone)

ACM (Wildcard + root)

CloudWatch basique

MongoDB Atlas Free Tier (variable)
