✅Phase 3 : CI/CD GitHub Actions (Backend + Frontend)

Objectifs : Obtenir les workflows GitHub Actions complets avec AWS OIDC, déploiement EC2+S3+CloudFront.


Je veux créer des pipelines CI/CD complets pour Cinephoria :

Backend ASP.NET 8 → EC2 Docker Compose

Frontend Angular 19 → S3 + CloudFront


👉 Le workflow CI/CD doit déployer deux stacks Docker différentes sur la même EC2 :

Staging : déploiement du service Docker exposé sur port 5001

Production : déploiement du service Docker exposé sur port 5000

👉 Les deux docker-compose seront nommés :

docker-compose.prod.yml

docker-compose.staging.yml

👉 Le reverse proxy Nginx déjà installé dirige les bons sous-domaines vers les bons ports.




Outils :

GitHub Actions + OIDC (pas de keys)

Docker

Nginx

AWS CLI

Branches :

feature/* → tests

develop → déploiement staging

main → déploiement production

tags v* → déploiement production

Génère TOUS les éléments suivants :

🟦 Workflow BACKEND (backend-deploy.yml)

Étapes :

→ Tests

restore

build

test

SAST .NET analyzers

→ Build Docker

image tag (staging/prod)

→ Déploiement EC2

connexion via SSH ou SSM

docker compose pull/up

🟧 Workflow FRONTEND (frontend-deploy.yml)

Étapes :

→ Tests

→ Déploiement S3 + CloudFront

sync dist/ → bucket
